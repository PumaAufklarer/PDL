# 00 · 深度学习到底在干什么

> **一句话**：传统编程是你把规则写进代码；深度学习是你写一套**流程**，让规则从数据里自己长出来。
>
> **对应 D2L**：1.1 引言、1.2 关键组件、1.3 各种机器学习问题 ｜ **对应 Stage**：0 ｜ **对应代码**：整个仓库 `src/pdl/`
>
> 这一章你一行 `pdl` 代码都不用写。它只干一件事：让你在动手之前，知道自己在造什么。

---

## 为什么需要它

几个月后导师给你一个 Issue：`stage1: implement matmul for Tensor`。你会写。
但你可能答不上来：**为什么一个深度学习库必须有 `matmul`？**

再往后你会写 `loss.backward()`、`optimizer.step()`。
这些函数为什么长这样、为什么顺序不能换、为什么少写一个 `zero_grad()` 就炸——
脑子里没有全局图，你就只能靠背。所以这一章不给代码，给地图。

### 传统编程 vs 机器学习

**传统编程**：规则是你写的。

```python
def is_spam(text: str) -> bool:          # 规则由人写
    return "中奖" in text or "免费" in text or "点击链接" in text
```

能用，但很脆。发垃圾邮件的人把"中奖"写成"中浆"，你的规则就废了。
你补一条，他绕一条，**你永远慢一步**。

**机器学习**：规则从数据里学出来。
你给程序 10 万封**已经标好**的邮件，程序输出的不是一段 `if`，而是一堆数字（**参数**）。
这堆数字就是它学到的规则，只不过没法翻译成人话。

判断一张图是不是猫也是同一回事：传统编程要手写"尖耳朵 + 胡须 + 花纹"，
机器学习是喂几万张标好的图，让它自己调那堆数字。

**一句话**：人从"写规则"退到"设计学习流程"。这一退，就是整个深度学习。

## 直觉：学做菜

把训练模型想象成你在厨房里学做一道菜。

- **模型** = 菜谱。它规定"放什么、按什么顺序、怎么处理"，然后端出一盘菜。
- **损失** = 尝一口。你没法直接算出"还差 3 克盐"，但你能尝出"这盘太咸了"。
  损失就是那个**能比较好坏的数字**，越大越难吃。
- **优化** = 调火候、加调料。尝到咸了下次少放点，淡了多放点。一次只改一点点，改完再尝。

三个关键点全在这个类比里：

1. 你**不需要**事先知道完美菜谱长什么样，只需要能尝出好坏。
2. 一次改一点点，比一次改一大勺更容易成功。改太猛，整盘菜直接没法吃（loss 发散）。
3. 有个**记录本**（自动微分）帮你记住"刚才加了哪几味、各加了多少"，
   否则你尝出咸了也不知道该退哪一步。

摆盘好不好看（准确率）是给别人看的，你厨房里真正关心的是**味道**（损失）。

## 最小数学

> 看不懂就跳过，先去做「落到代码」，回来再读。

这一章只有两个公式，但它们是整本书的目标。

### 1. 训练就是解一个最小化问题

$$\theta^{*} = \arg\min_{\theta} \; \frac{1}{N}\sum_{i=1}^{N} \ell\big(f_{\theta}(x_i),\, y_i\big)$$

- $x_i$ / $y_i$：第 $i$ 条输入和它的正确答案
- $f_{\theta}$：**模型**，$\theta$ 是它的全部参数
- $\ell$：**损失函数**，衡量"预测和答案差多少"
- $\frac{1}{N}\sum$：把 $N$ 条样本的损失**平均**成一个数
- $\arg\min_\theta$：找一组 $\theta$，让这个平均数最小

**为什么是平均不是求和？** 平均之后损失大小和批量大小无关。
换个 batch size 结果就变，你没法比较实验。

### 2. 参数怎么动

$$\theta \leftarrow \theta - \eta \, \nabla_{\theta} L(\theta)$$

$\nabla_\theta L$ 指向"损失上升最快"的方向，所以往**反方向**走；
$\eta$ 是**学习率**，一次走多远，它是个超参数，不是学出来的。

整条链路：**模型 → 预测 → 损失 → 梯度 → 更新 → 再预测**。
`pdl` 的每个子包都是这条链上的一环。

## 落到代码

这一章的"代码"是仓库的整体地图：

| 子包 | 职责 | 属于三要素里的哪个 | Stage |
|------|------|--------------------|-------|
| `utils/` | 数值梯度校验器、随机种子、实验记录 | 地基（验证一切） | 1 |
| `data/` | `Dataset` / `DataLoader` / 批采样 | 地基（喂数据） | 2 |
| `loss/` | MSE、交叉熵 | **损失** | 2–3 |
| `optim/` | SGD、Momentum、Adam | **优化**（用梯度） | 2–4 |
| `trainer/` | 训练循环、验证、早停、日志 | 把上面全部串起来 | 2–4 |
| `metrics/` | 准确率、混淆矩阵 | 评估（**不是**损失！） | 3 |
| `nn/` | `Linear` / `ReLU` / `Dropout` / `Sequential` | **模型** | 4–5 |

注意表里没有"张量"和"自动微分"：这两样**直接用 PyTorch 的**，不由我们实现。原因见下面第 2 条。

### 三要素是**独立**的

这是本章最值钱的一句话，后面每章都会回来。

| 要素 | 回答的问题 | 换掉它意味着 |
|------|-----------|--------------|
| 模型 | "我能表达哪些函数？" | 线性回归 → MLP，表达力变强 |
| 损失 | "我怎么判断预测好不好？" | MSE → 交叉熵，从回归换到分类 |
| 优化 | "我怎么在参数空间里找？" | SGD → Adam，找得更快更稳 |

同一个模型能配不同损失，同一个损失能配不同优化器。
**别把它们搅在一起想**——`pdl` 的目录结构就是把它们物理隔开。

### 参数 vs 超参数

| | 参数 | 超参数 |
|---|------|--------|
| 谁决定 | 从数据里学出来 | 你拍板 |
| 训练中会变吗 | 每个 batch 都变 | 不变 |
| 例子 | 权重 $W$、偏置 $b$ | 学习率、批量大小、层数、正则系数 |

判别口诀：**会被 `optimizer.step()` 更新的，是参数；不会的，是超参数。**

### 训练集 / 验证集 / 测试集

训练集用来更新参数；验证集用来**做选择**（选超参数、选模型、决定何时停），
你**不能**用它更新参数；测试集最后只用一次，报个数字给别人看。

一句话：**你不能拿考试题来复习。** 第 06 章会详细讲怎么切、切错了会怎样。

## 工程视角

这一章的"工程"不是写代码，是**把流水线跑通**。Stage 0 的全部意义在这。

### 1. 为什么要先走一遍空 PR

第一个 PR 刻意**零技术难度**（改个 typo 就行），因为要学的是流程本身：
建分支、提 PR、看 CI 日志、回应 review、合并。
等你 Stage 2 卡在自动微分里时，不该同时还在纠结"CI 红了去哪看日志"。
**一次只引入一个新东西**，这是路线图的第 4 条原则。

### 2. 为什么"跑通 ≠ 理解"

`import torch; loss.backward()` 三分钟就能抄会，但它是黑盒：
梯度怎么算出来的？为什么 `(3,1)` 和 `(1,4)` 相加后反向要**求和**回去？为什么 loss 必须是标量？

这个仓库**用 torch 的张量和自动微分当底层，但上层全部由你自己写**——层、损失、优化器、数据管道、训练循环。
所以你写出来的东西不会比 PyTorch 快，但它上面每一块你都知道是怎么来的。
到 Stage 7 你才会用 `torch.nn` 把同一个模型再写一遍做对照，那时候你已经知道那些封装里装的是什么了。

### 3. 会卡住，而且这是设计好的

路线图里每个 Stage 都有"降级预案"：手推反向卡住，允许先只做不含激活的 `Linear`（推导最短）；模块系统太绕，允许 `Sequential` 只收一层列表。**降级不是失败，硬扛到放弃才是。** 卡住超过 2 小时，直接找导师，别耗。

## 常见误解

| 误解 | 实际 |
|------|------|
| "深度学习就是让电脑自己思考" | 它是在你指定的假设空间里做数值搜索，没有"理解"这回事 |
| "数据越多越好" | 没有验证集，你连"模型变好了"都判断不了。质量和**对齐**比数量重要 |
| "模型越大越好" | 参数多 = 自由度多，也是过拟合的源头，第 05、08 章都在治它 |
| "loss 下降就说明模型变好了" | 训练 loss 下降只说明它在**记住**训练集，要看两条曲线的 gap |
| "超参数也能靠梯度下降学出来" | 那是外层搜索，`optimizer.step()` 碰不到超参数 |
| "先把 D2L 读完再动手" | 700 多页，读完你就放弃了。先读手册 → 读对应小节 → 写代码 |
| "抄一遍 D2L 的 notebook 就是学会了" | 抄的时候代码没有 bug，所以你没机会理解任何东西 |
